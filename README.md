# BDS (Batavia Delight Signature) — Boutique Fashion & Catalog

Website profil butik, katalog produk, dan *interactive modest luxury lookbook* untuk **BDS (Batavia Delight Signature)**.

Terinspirasi dari pendekatan visual **Batavia Framer** (*high-end editorial*, *warm-earthy*, dan *luxury modest*).

## ✨ Fitur Utama
- **Identitas Visual Editorial:** Tipografi anggun (*Playfair Display*, *Cormorant Garamond*, & *Plus Jakarta Sans*) dengan palet warna *Warm Alabaster* (`#F9F6F0`), *Deep Espresso* (`#231F20`), dan *Muted Champagne Gold* (`#C5A880`).
- **Minimalist Brand Navbar:** Header bersih dan elegan yang hanya berfokus pada logo resmi BDS.
- **Floating Concierge & Cart:** Tombol mengambang (*floating dock*) untuk akses cepat ke WhatsApp Admin Concierge dan Tas Belanja.
- **Interactive Lookbook (Hotspots):** Galeri interaktif dengan titik-titik sorot (*hotspots*) yang memunculkan kartu detail produk saat disentuh.
- **Katalog & Filter Seamless:** Filter kategori (*Koleksi Lebaran, Hijab & Voal, Parfum & Skincare*), filter warna (*color swatches*), live search modal, dan pengurutan harga.
- **Product Detail Modal (PDP):** Pop-up interaktif untuk pemilihan varian warna, ukuran (S, M, L, XL), accordion *Material & Care*, serta tabel panduan ukuran.
- **Slide-over Cart Drawer:** Keranjang belanja samping dengan pengatur kuantitas, kode voucher promo `BDSLUX` (diskon 10%), dan indikator *Free Shipping Progress*.
- **Dual Checkout System:**
  1. **Order via WhatsApp Admin:** Membuat draft pesan pemesanan otomatis yang rapi dan terstruktur ke WhatsApp admin.
  2. **Direct Checkout:** Formulir ringkasan pesanan lengkap untuk metode Transfer Bank & QRIS.

## 🚀 Menjalankan Secara Lokal
Cukup buka file `index.html` pada browser apa pun (Google Chrome, Edge, Safari, Firefox).
Atau jalankan live server lokal sederhana:
```bash
npx serve .
```
